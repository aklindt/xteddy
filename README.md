I remebered this cute decorative desktop teddy from my early Linux days almost 30 years ago.
It is still available in the Debian repositories and it can easily be installed on its derivates like AntiX Linux.
But in other distributions like Manjaro or in Arch's aur it is long gong. I couldn't find it on github either.
I think, that's a pitty. Sometimes all you need to make you smile is a cute little something that does nothing.
Xteddy does nothing else, but looking cute. And I wanted to preserve it. 

It should compile with a classic:

./configure
make
make install
